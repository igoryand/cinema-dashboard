# Продуктовая аналитика онлайн-кинотеатра

Дашборд в DataLens для анализа активности пользователей и удержания в онлайн-кинотеатре. Объединяет ключевые метрики в одном месте и позволяет изучать их динамику и распределение по устройствам.

### Структура дашборда

- **Обзор на день** — ключевые показатели за день и доля устройств.
- **Активность** — количество пользователей и зрителей, запуски и завершения просмотров, среднее количество запусков на зрителя и относительные метрики активности. Динамика показателей за дни и недели.
- **Удержание** — D1, D7 и D30 Retention: количество вернувшихся пользователей, доля удержания и динамика по когортам.

### Данные

Используются синтетические события пользователей. Подготовка данных и расчёт метрик выполняются в Python с помощью pandas, визуализация — в Yandex DataLens.
